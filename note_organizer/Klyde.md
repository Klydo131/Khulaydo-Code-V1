Write whatever you want here. This reader will display it
page by page, with full navigation using your keyboard.

You can use all standard Markdown formatting:

- **Bold text** stands out clearly
- *Italic text* adds emphasis
- `code snippets` appear in a distinct color

---

## Chapter 2 — How to Use This Reader

Open `Klyde.md` in any text editor to write your content.
Then launch the reader to read it back in style.

**Navigation keys:**

- ↓ / j / Space — next page
- ↑ / k — previous page
- g — jump to the first page
- G — jump to the last page
- q — quit
